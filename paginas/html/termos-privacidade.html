Segurança

Regras simples para uso responsável do site.

Como o site possui cadastro e formulários, é importante explicar como os dados devem ser usados e protegidos.

Organização e responsabilidade também fazem parte do cuidado com as pessoas.

Termos de uso

Uso correto da plataforma.

O usuário deve informar dados verdadeiros, respeitar as regras do projeto e utilizar o site apenas para finalidades solidárias.

Dados pessoais

Nome, telefone e email devem ser usados somente para contato relacionado ao projeto.

Privacidade

Informações sensíveis de famílias atendidas não devem ser expostas publicamente.

Responsabilidade

Doações e solicitações precisam ser analisadas pela equipe antes da confirmação.

Finalidade

O site tem objetivo acadêmico e social, demonstrando uma solução para organização de caridade.
