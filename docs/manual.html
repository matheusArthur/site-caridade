Projeto Caridade

Um site para aproximar pessoas que querem doar de quem precisa de apoio.

Voltar para a apresentação

Sobre o projeto

Utilizei HTML, CSS e JavaScript para criar as páginas. O Firebase cuida das contas dos usuários e do salvamento dos dados.

Como funciona

  1. Crie uma conta ou entre com seu e-mail e senha.
  2. Consulte os itens disponíveis por categoria.
  3. Para doar, preencha os dados do item e escolha uma foto ou um link de imagem.
  4. No perfil, altere sua foto, contato, região e participação.
  5. Acompanhe as fotos das novas doações feitas pela sua conta.

Melhorias realizadas

  • Mensagens mais claras nos formulários.
  • Correção da identificação da conta ao cadastrar uma doação.
  • Bloqueio de envios repetidos e manutenção dos dados em caso de erro.
  • Inclusão de fotos com prévia e redução do tamanho do arquivo.
  • Salvamento da foto e dos dados editáveis do perfil.
  • Ajustes na navegação pelo teclado e na organização da Home.

Como executar

Com Python 3 instalado, execute na pasta do projeto:

python -m http.server 5500 --directory paginas

Depois, abra localhost:5500.

As contas e o salvamento dos dados dependem da configuração do Firebase e das permissões do banco.

Testes

Incluí testes automáticos para conferir os formulários e as principais alterações. Eles usam respostas simuladas e não substituem os testes com o Firebase real.

Com Node.js instalado, execute:

node tests/run.cjs
