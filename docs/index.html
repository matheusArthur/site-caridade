Sobre o projeto

Desenvolvi o Projeto Caridade para aproximar pessoas que querem doar de quem precisa de apoio. O site reúne informações sobre iniciativas solidárias e permite cadastrar e consultar itens para doação.

O público inclui doadores, pessoas que procuram itens e interessados em conhecer formas de contribuir com a comunidade.

Funcionalidades

  • Criar uma conta, entrar e recuperar a senha.
  • Cadastrar doações e consultar itens por categoria.
  • Escolher uma foto do aparelho ou usar um link de imagem.
  • Visualizar a foto antes de enviar e reduzir seu tamanho automaticamente.
  • Salvar a foto do perfil e editar contato, região e participação.
  • Ver até quatro fotos das novas doações feitas pela própria conta, sem valores.

Principais melhorias

Melhorei as mensagens dos formulários, a organização do login no celular e a navegação pelo teclado. Também corrigi a identificação da conta ao doar e impedi envios repetidos durante o salvamento.

No perfil, incluí o salvamento da foto e a edição dos dados pessoais. No cadastro de itens, acrescentei a opção de anexar imagens. Mantive o padrão visual do site durante os ajustes.

Home e imagens

Organizei quatro opções de contribuição: alimentos, roupas, higiene e tempo. Simplifiquei a página e distribuí imagens diferentes pelos cabeçalhos.

Utilizei seis imagens ilustrativas geradas por inteligência artificial. Elas representam a proposta do site e não são registros de ações reais do projeto.

Tecnologias

Utilizei HTML, CSS e JavaScript nas páginas. O Firebase Authentication cuida das contas, e o Cloud Firestore salva os dados e as imagens pequenas.

Como executar

Com Python 3 instalado, execute na pasta do projeto:

python -m http.server 5500 --directory paginas

Depois, abra localhost:5500. As contas e o salvamento dependem da configuração do Firebase e das permissões do banco.

Contribuição esperada

Com o projeto, busco facilitar a divulgação de itens e aproximar quem deseja ajudar de quem procura apoio. Esse é o benefício esperado; ainda não tenho dados para medir seu impacto na comunidade.

Próximos ajustes

Alguns formulários ainda não enviam dados. O histórico de itens adquiridos precisa ser separado por usuário, e as permissões dos produtos precisam de melhorias. O site não processa pagamentos.
